Cómo funcionaDel guion al globo, todo en una máquina.

datos/ guiones/*.json · infraestructura · organizaciones · cables
   │
   ▼
simulador   guion + semilla → flujos con timing        determinístico
   │
ruteo       destino → hops (router→ISP→IXP→cable→DC)  topología pública
   │
detección   5 reglas explicables + línea de base      evidencia, no puntaje
   │           dispositivo_nuevo · destino_nuevo · asn_desconocido
   │           volumen_inusual · cambio_ruta → secuencia_exfiltracion
   ▼
asistente   Ollama qwen2.5:7b local → castellano      fallback a plantillas
   │
FastAPI     REST + WebSocket /ws/flujos · SQLite · PDF · CSV
   │
   ▼
interfaz    globo · alertas · resumen de turno · guiones
  • Determinismo: misma semilla, misma demo. Se ensaya diez veces y sale igual.
  • La IA no decide, explica. La detección es de reglas; si el modelo no contesta la alerta sigue siendo correcta.
  • Todo versionado: datos, contratos, guiones y código en el repo, con sus commits.
  • Stack: Python · FastAPI · SQLite · Ollama · HTML/JS. Dependencias MIT/Apache.

Soberanía tecnológicaCortamos internet. Sigue andando todo.

  • Globo, tráfico, alertas y asistente sin una sola petición externa. Verificable en la pestaña Red del navegador.
